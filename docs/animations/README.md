# 네비게이션 GIF

| 파일 | 내용 |
|---|---|
| [navigation-flow.gif](navigation-flow.gif) | 실제 앱에서 상품·장바구니·주문 피처를 오가는 하나의 연속 플로우와 대응하는 소스 코드 |
| [registration-flow.gif](registration-flow.gif) | Factory.create → Hilt → Registry → entry<Route> → NavDisplay 등록 코드 |

화면은 Android API 36 에뮬레이터에서 실제 앱을 조작해 연속 녹화했으며 1.6배속으로 재생됩니다.

코드 강조는 녹화된 클릭에 대응하는 소스 설명 애니메이션이며, 카드 디자인은 [Carbon](https://carbon.now.sh/)과 [Ray.so](https://ray.so/) 스타일을 참고해 로컬에서 렌더링했습니다.

소스 커밋·파일별 해시·코드 범위·GIF 해시는 [manifest.json](manifest.json)에 기록했습니다.
